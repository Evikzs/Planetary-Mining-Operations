## How to verify

- `npm run check`, `npm run bot`, then e2e.
- This cloud container is slow for the browser e2e suite (SwiftShader at load 8 on 4 cores: about 2 hours for the full suite, and the core loop passes its 300 s timeout). CI runs the suite in about 17 minutes. So: run the new or changed specs locally, push the work branch, and let CI judge the full suite. The deploy branch moves only on green CI.
- Never edit `e2e/` while a local Playwright run is going: it loads spec files as it goes. Run local e2e from a separate git worktree pinned to a commit.
- The perf budgets in `tests/perf` (median fine tick < 4 ms, encode < 60 ms) are noisy on this container while anything else runs; CI judges them.
- The app smoke test needs `xvfb-run -a` and SwiftShader switches (already in the test).
